Swyx · smol_ai / dxtips / Cognition / AI Engineer / Latent Space

用线程拼出早期 multi-agent 工作流

Swyx 描述了一种原始但实用的近未来 multi-agent 模式：让一个线程在完成后 ping 回来，从而形成隐式的 kanban 或 waterfall 依赖图；每个线程保留自己的上下文、工作结果和 agent 状态。他认为现在已经可以在多数 coding agents 中手工搭出这一模式，只是还缺一个更好的 UI。

Peter Yang · Practical AI tutorials and interviews

给 Codex 和 Claude Code 加一个 /human-review 视觉审阅环节

Peter Yang 发布了新的 /human-review skill，用于直接编辑 HTML 和 Markdown 文件。用户可让 Codex 或 Claude Code 安装该 skill，然后输入 /human-review 加文档名，打开可视化编辑器修改文字、调整图片、像 Google Doc 一样留下反馈，最后点击“Send to agent”让 AI 应用修改。他把它定位为 agent 完成最后 10% 打磨时的人类审阅层。

Madhu Guru · Sr Director, AI at Meta

AI 普及慢，是因为产品仍要求用户理解实验室黑话

Madhu Guru 认为 AI diffusion 偏慢的原因之一，是产品把用户带到空白窗口前，要求他们写 prompt、选 model、判断是否需要 agent，还要理解 context windows、reasoning、MCP、memory、skills 等概念。多数用户并不关心这些术语，只想把事情完成。他预计未来 12 个月会出现一个能突破这一问题的产品。

企业场景将消耗全球 99% 的 token
