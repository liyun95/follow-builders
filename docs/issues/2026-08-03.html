Aaron Levie · ceo @box

可验证领域可能最先被自动化

Aaron Levie 指出，一些世界上最“难”的工作可能因为可验证性而更早被自动化，尤其是 math、cyber 和 code。这些领域能客观测试正确性，因此既能为模型训练提供更清晰的 reward signals，也能在运行时规模化验证结果。相比之下，法律、营销、销售、财务规划等知识工作没有单一正确答案，依赖上下文、操作者偏好和风险水平，因此 applied AI layer 和流程重构仍会很重要。

AI 带来的 agency rupture 会经历三阶段重建

Core Automation 谈自动化 AGI Lab、transformer 边界与 test-time learning

本期 Training Data 采访 Core Automation 的 Jerry Tworek 和 Rohan Anil。Jerry 认为，过去几年行业已经掌握了大规模 pre training 和大规模 reinforcement learning，但更聪明系统的瓶颈可能在 architecture 本身。他提出，模型在 lab 中训练、却在真实世界分布上部署，这是核心张力；benchmark 与训练任务相近，但现实任务更混乱。因此未来需要能在 test time 与用户数据、真实任务一起学习的模型。现有 in-context learning 受上下文长度限制，fine tuning 又有 catastrophic forgetting 与数据效率问题，可能需要在架构层表达新的 meta learning 算法。
